芯片替代料匹配工具——试用说明

1. 请先完整解压收到的 ZIP，不要直接在压缩包中运行。
2. 双击“芯片替代料匹配工具.exe”启动；无需安装 Python 或 Visual Studio Code。
3. 手动输入参数和本地候选匹配可以离线使用。
4. 自动识别类型及自动填参需要联网，并需要用户自己的 DeepSeek API Key。
5. 制造商通常留空；只有 DeepSeek 提示同型号重名或有歧义时才选择制造商并重试。
6. API Key 默认隐藏，只在本次程序运行中使用，不会写入候选 CSV 或匹配结果。
7. DeepSeek 自动填写的参数必须对照原厂规格书核对，尤其是封装、Pinout、单位和测试条件。
8. 请保留整个程序文件夹。不能只复制 EXE，否则程序会缺少运行依赖和候选数据。
