# 芯片替代料智能匹配工具

双击 `启动匹配工具.bat` 打开桌面 GUI。程序会自动读取 `products/MCC/clean` 中清理后的 MCC CSV，无需先运行 Notebook。

`clean` 中的文件采用 UTF-8 单表头标准 CSV：第一行是规范化字段名，第二行开始全部是数据，可以直接用于 Pandas、数据库导入或其他程序，不需要 `skiprows`。

使用方法：

`products/MCC/clean` 中的 CSV 只作为本公司的候选物料库。客户正在使用的型号和参数由客户在界面中输入，程序不会要求客户型号已经存在于 MCC CSV 中。

1. 选择客户物料所属类型。
2. 输入客户当前使用的型号（可选）及其规格参数。
3. `封装类型`为必填硬约束；配置、功能数、极性、沟道等分类参数填写后也作为硬约束。
4. 电气参数至少填写一项，空白参数不会参与匹配。
5. 点击“开始匹配”，程序只从相应的 MCC CSV 中推荐候选物料。
6. 结果先按关键参数状态（通过、待确认、不满足）分层，再按综合得分排列，可导出 CSV。

## 更新和清理 MCC 产品表

将 MCC 原始导出表放入 `products/MCC/raw`，然后运行：

```powershell
python clean_catalogs.py
```

脚本会把清理后的 CSV 写入 `products/MCC/clean`，原始文件不会被修改。清理规则：

- 数据区整列为空时删除该列，因此 GUI 不再显示该参数。
- 没有字段名的列也会删除并记录，因为无法判断其参数含义。
- 原始产品类别行和单位行不写入 clean 文件；字段单位保留在字段名中。
- 字段名中的换行、不间断空格和连续空格会合并成普通空格。
- 所有局部 NA 都保持未知，不再用近邻中位数填补。
- 如果物料的任意参数字段含逗号，删除整颗物料。
- 所有删列、删料和保留空白数量都记录在 `products/MCC/cleaning_report.md`。

## 缺失感知匹配

- 只比较客户物料和候选物料双方都有值的参数，不会把 NA 替换成虚构值。
- `参数覆盖率`表示客户已填参数中有多少权重得到候选数据支持；覆盖率低于 50% 不推荐。
- Gower 相似度和参数覆盖率继续负责整体接近程度；方向规则是独立的产品配置层。
- 产品方向规则集中配置在 `matching_rules.py`，目前已启用 MOSFET、Switching Diode、SBD、FRED、Transistor、Zener、TVS 和 ESD。
- MOSFET：VDS、ID 要求替料不低于原料；RDS(on)、Qg、Trr、Qrr 要求替料不高于原料；VGS(th) Min/Max 要求相对偏差在 ±20% 内。
- 当前 MCC MOSFET 表没有 Qg、Trr、Qrr 字段；配置已准备好，今后 CSV 增加对应列后会自动生效。
- Power MOSFET 和 Small Signal MOSFET 的 `Channel=N+P` 参数按 `N值/P值` 解析；GUI 会自动切换为独立的 N沟道、P沟道输入框。
- N+P 关键方向规则逐侧检查，N、P 任一侧失败即标记“不满足”；关键字段缺少一侧时标记“待人工确认”。字段原始双值会完整保留在推荐结果和导出 CSV 中。
- N+P 的单值 VGS 视为两侧共享额定值；其他关键参数不会把单值自动复制到 N、P 两侧。
- GUI 会自动识别以 `±数值` 为主、仅含少量明确 `+正值/-负值` 例外的字段并预填 `±`；裸 `±` 仅作为输入提示，不参与匹配计算。
- 单通道 MOSFET 的非对称 VGS（如 `+20/-16`）会分别比较正、负额定值，再取平均相似度。
- 标记为“关键”的规则会影响通过/待确认/不满足状态；“尽量较小/较大”等非关键规则作为方向偏好，不淘汰候选。
- 方向偏好占综合得分的 15%，Gower 接近度仍是主体。候选处于期望方向时方向得分为 100%，处于反方向时按相对偏差平滑扣分。
- Query 已填写但 Candidate 缺失关键参数时标记“待人工确认”；明确违反关键方向规则时标记“不满足”并降分。通过规则的候选始终优先显示。
- 结果同时显示综合得分、已知参数匹配度、覆盖率、可信度、缺失参数及风险提示。
- 相同封装名称不等于 Pinout 和尺寸已经验证，最终仍须核对原厂规格书。

若需要重新安装环境：

```powershell
python -m pip install -r requirements.txt
python app.py
```

匹配核心位于 `matching_model.py`，GUI 位于 `app.py`。后续可以在不改界面的情况下继续调整权重和约束逻辑。
